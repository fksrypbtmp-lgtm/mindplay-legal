# MindPlay Legal

Static, bilingual public pages for MindPlay Privacy and Support.

Current publication status: **public technical draft, not store-ready**. The
pages remain `noindex` while publisher, contact, hosting, and retention details
are unresolved.

The approved legal drafts live in the main product repository. This repository
contains only the rendered public pages derived from those approved sources.

## GitHub Pages

- source: branch `main`, repository root;
- Privacy: `/privacy/`;
- Support: `/support/`;
- HTTPS must be enabled before mobile distribution.

No analytics, tracking, remote fonts, cookies, or external JavaScript are used.
