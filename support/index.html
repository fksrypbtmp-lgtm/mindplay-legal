Support MindPlay — Français

Canal de contact : bientôt disponible. Aucun compte utilisateur n’est nécessaire.

Quand le canal sera ouvert, les demandes seront triées, rapprochées d’un code incident si disponible, puis escaladées à l’équipe technique en cas de panne ou de défaut confirmé.

Avant de signaler un problème

Préparez uniquement :

  • version et build de MindPlay ;
  • plateforme iOS ou Android ;
  • langue utilisée ;
  • code incident, s’il est affiché ;
  • description et étapes générales.

N’envoyez jamais de mot de passe, token, clé, solution complète, mouvements, chemins, placements ou définition de puzzle.

Questions fréquentes

Où ma progression est-elle enregistrée ?
Uniquement sur cet appareil. Une désinstallation peut l’effacer.
Le Défi du jour ne charge pas.
Il nécessite le réseau. Réessayez plus tard ; les autres jeux restent accessibles.
Puis-je jouer entièrement hors ligne ?
Non. Les nouveaux catalogues, puzzles et le Daily nécessitent le backend.
Mes données sont-elles synchronisées ?
Non : aucun compte et aucune synchronisation cloud.
Comment changer la langue ou les vibrations ?
Utilisez Réglages dans l’application.
Pourquoi certains titres restent-ils en français ?
Certains titres sont encore fournis en français par le backend.

MindPlay Support — English

Contact channel: coming soon. No user account is required.

Once the channel is available, requests will be triaged, correlated with an incident code when available, and escalated to Engineering for confirmed incidents or defects.

Before reporting a problem

Prepare only:

  • MindPlay version and build;
  • iOS or Android platform;
  • selected language;
  • incident code, when displayed;
  • a description and general reproduction steps.

Never send a password, token, key, full solution, moves, paths, placements, or puzzle definition.

Frequently asked questions

Where is my progress stored?
Only on this device. Uninstalling the app may erase it.
The Daily Challenge does not load.
It needs a network connection. Try again later; other games remain available.
Can I play fully offline?
No. New catalogs, puzzles, and the Daily Challenge require the backend.
Is my data synchronized?
No. MindPlay has no account or cloud synchronization.
How do I change language or vibrations?
Use Settings inside the app.
Why are some titles still in French?
Some titles are still supplied in French by the backend.
